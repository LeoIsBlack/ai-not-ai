# AI not AI — портфолио ИИ-видео

Портфолио студии ИИ-видео: рекламные ролики, клипы, анимация, ИИ-персонажи и контент для соцсетей.

🌐 **Сайт:** [https://leoisblack.github.io/ai-not-ai/](https://leoisblack.github.io/ai-not-ai/)

## О проекте

Одностраничный статический сайт без сборщиков и внешних зависимостей. Работает напрямую в браузере и на GitHub Pages.

## Структура файлов

- `works.js` — все редактируемые данные сайта: контакты (`SITE`) и список работ (`WORKS`)
- `index.html` — разметка страницы и тексты разделов
- `style.css` — стили, сетка, адаптив и светлая/тёмная темы
- `app.js` — логика карточек, фильтров, модального окна и кастомного видеоплеера
- `covers/`, `videos/` — локальные обложки и видеоролики
